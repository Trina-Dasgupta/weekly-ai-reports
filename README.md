# weekly-ai-reports

A personal AI research library that grows by one week at a time. It is generated each Monday for the previous ISO week (Asia/Kolkata).

| Folder | Contents |
|---|---|
| `research-papers/YEAR/week-XX/` | Original paper PDFs, deep per-paper analyses, architecture docs, Mermaid diagrams, weekly research report |
| `ai-news/YEAR/week-XX/` | Weekly AI news report and source list |
| `weekly-ai-digests/YEAR/week-XX/` | Unified weekly intelligence digest and a 10–15 minute overview |
